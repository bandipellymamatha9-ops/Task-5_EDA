# Titanic-Style Passenger EDA

## Project description
This beginner-friendly project explores a passenger dataset using Exploratory Data Analysis (EDA) with Python, Pandas, Matplotlib and Seaborn.

**Dataset note:** `titanic_passengers_sample.csv` is a synthetic Titanic-style sample created for learning. It is not the original historical Titanic dataset. It contains 500 rows and a few missing values for data-cleaning practice.

## Files
- `titanic_passengers_sample.csv` – dataset used in the project.
- `titanic_eda_analysis.ipynb` – Jupyter Notebook with analysis and visualisations.
- `titanic_eda_findings_report.pdf` – PDF report with charts and observations.
- `requirements.txt` – required Python libraries.

## How to run
1. Keep all files in the same folder.
2. Install libraries using `pip install -r requirements.txt`.
3. Open `titanic_eda_analysis.ipynb` in Jupyter Notebook.
4. Run the cells from top to bottom.

## Analysis included
Dataset information, descriptive statistics, value counts, missing-value handling, histogram, bar plots, boxplot, scatterplot, correlation heatmap, pairplot and summary observations.
